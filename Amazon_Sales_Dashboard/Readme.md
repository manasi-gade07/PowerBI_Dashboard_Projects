# 🔍 Amazon Sales Analysis Dashboard

## 📊 Explore E-commerce Sales Trends and Revenue Insights

This project showcases a Power BI dashboard that analyzes Amazon sales data, offering insights into product performance, shipping, and fulfillment methods.

### ✨ Key Highlights:

- **🛍️ Top 5 Product Categories by Sales**  
  Discover the highest performing product categories based on sales data.

- **🚚 Delivery Partner & Courier Status Insights**  
  Analyze delivery partners and courier performance to identify areas of improvement.

- **📦 Fulfillment Method & Shipping State Analysis**  
  Gain insights into how fulfillment methods and different shipping states impact sales.

- **📅 Dynamic Filters for Time & Location**  
  Use filters to view sales trends over different periods and regions for more targeted insights.

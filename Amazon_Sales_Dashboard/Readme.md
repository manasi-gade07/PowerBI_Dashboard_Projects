# 🔍 Amazon Sales Analysis

## 📊 Analyze E-commerce Sales Trends and Revenue Insights

This project provides in-depth analysis of e-commerce sales trends, focusing on Amazon sales data. Key insights are derived to help optimize business strategies, improve operational efficiency, and maximize revenue.

### ✨ Key Highlights:

- **🛍️ Top 5 Product Categories by Sales**  
  Discover the highest performing product categories based on sales data.

- **🚚 Delivery Partner & Courier Status Insights**  
  Analyze delivery partners and the status of couriers to identify bottlenecks and opportunities for improvement.

- **📦 Fulfillment Method & Shipping State Analysis**  
  Gain insights into the most efficient fulfillment methods and how different shipping states affect overall sales.

- **📅 Dynamic Filters for Time & Location**  
  Apply dynamic filters to analyze sales trends based on **time** (daily, weekly, monthly) and **location** (region, country) for deeper insights.

## 🚀 Getting Started

### 🛠️ Prerequisites

Make sure you have the following libraries installed:
- `pandas`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `numpy`

To install these libraries, run the following command:

```bash
pip install pandas matplotlib seaborn scikit-learn numpy
````

### 🖥️ Clone the Repository

Clone this repository to your local machine:

```bash
git clone https://github.com/yourusername/amazon-sales-analysis.git
```

## 📊 Data

The data includes sales, product categories, delivery status, and shipping information. Key columns include:

* **Product ID**
* **Product Name**
* **Sales Volume**
* **Category**
* **Fulfillment Method**

* **Customer Demographics**
